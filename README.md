### Описание заданий

#### Задание 1 (Простое): Определение знака числа
- **Класс:** `Task1_NumberSign.java`
- **Суть:** Программа принимает целое или вещественное число и определяет, является ли оно положительным, отрицательным или равным нулю. Реализованы проверки граничных значений, форматированный вывод и интерактивный ввод.

#### Задание 2 (Сложное): Алгоритм сортировки пузырьком (Bubble Sort)
- **Класс:** `Task2_BubbleSort.java`
- **Суть:** Классическая сортировка массива методом «пузырька» с оптимизацией флагом перестановок (`swapped`) для досрочного завершения на отсортированных последовательностях. Выводится пошаговый процесс сортировки, количество сравнений и перестановок.

### Инструкция по сборке и запуску

#### Вариант 1: Быстрый запуск (Windows)
Запустите командный файл:
```cmd
run.bat
```

#### Вариант 2: Запуск через терминал (javac / java)
```bash
# Компиляция:
javac -encoding UTF-8 Task1_NumberSign.java Task2_BubbleSort.java Lab1_Main.java

# Запуск:
java -Dfile.encoding=UTF-8 -cp . Lab1_Main
```
